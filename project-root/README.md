PROGETTO PCTO
il Progetto è una webapp sviluppata in python nella quale si possono inserire e visualizzare immagini.
necessario per accesso il server di lookback.
nell'interfaccia grafica sono presenti tre bottoni: il primo per l'inserimento dell'immagine tramite il file explorer, il secondo permette lo zoom e il rimpicciolimento dell'immagine insieme all'inserimento dei punti e infine il pulsanto save che deve restituire i punti 
il tasto edit non funziona se non viene inserita un immagine.
il tasto save non funziona se non vengono inseriti i punti
----------------------------------------------------------------------------------------------------------------------------------------------------------------------
tecnologie utilizzate 
python 3.14 
flask per la webapp
formato json per il salvataggio dei dati 
Tkinter per l'interfaccia
